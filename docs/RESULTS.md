# 结果

原始结果在 `docs/results/` 下：`analysis.json` 是现有数据的诊断，`diag_vlmjev_v2.json` 是诊断评测，`audit_2026-11-18.json` 是人工抽查记录。

## 1. 现有数据的问题（`glance_data.analyze`）

统计对象是 vlm-jev 训练集：24,407 张图，355,385 题。

| 问题 | 数字 |
|---|---|
| 具体程度两极分化 | RefCOCO/+ 的描述中位数是 3 个词，22–26% 连名词都没有（如 “green shirt”、“middle left”）；RefCOCOg 的中位数是 8 个词，18% 超过 12 个词 |
| 每个目标都有同类干扰物 | 100% 的训练目标在图中至少有 2 个同类物体，40% 至少有 4 个。所以“只说类别名”和“全部实例”这两种问法从没出现过 |
| 同类物体覆盖不全 | 面积 ≥0.5% 的物体中，只有 42% 有描述；54% 的图里，同一类物体只描述了一部分。小物体覆盖更低，例如背包 11%、瓶子 16%、杯子 20% |
| 负例太容易 | 78% 的负例提到的类别根本不在图里，14% 没有类别词，只有 7.7% 是“同类存在、描述不符” |
| 多目标描述被丢弃 | gRefCOCO 训练集中有 69,580 条多目标描述没被使用 |
| 语言和类别单一 | 全是英文；按用途描述的不到 1%；48% 的描述指向人 |

benchmark 的问题：

| 问题 | 数字 |
|---|---|
| 测不到“没有”和“多个” | RefCOCO / RefCOCO+ / RefCOCOg 的 8 个评测集里，负例和多目标题都是 0% |
| 评测集不独立 | refcoco_val、refcoco+_val、grefcoco_val 用的是同一批 1,500 张图；9 个评测集实际上只有 3 组图片 |
| 偏重位置词 | refcoco_testB 中 64% 的题只靠位置词就能答对 |
| 已经饱和 | vlm-jev v2 在 refcoco_val 上是 95.0%。随机抽 24 道错题：约 6 道是标注或句子本身有问题，约 6 道描述有歧义，约 5 道 IoU 刚好落在 0.45–0.50，真正的模型错误约 7 道 |

## 2. 标签正确率（分层人工抽查，每类 8 条）

| 题型 | 正确 | 题型 | 正确 |
|---|---:|---|---:|
| long | 8/8 | hneg_attribute | 8/8 |
| casual | 8/8 | hneg_relation | 8/8 |
| medium | 7/8 | neg_count | 8/8 |
| short | 6/8 | neg_position | 8/8 |
| group | 6/8 | neg_near | 7/8 |
| function | 6/8 | cat_all | 8/8 |
| cat_only | 5/8 | gref_multi | 8/8 |

总计 101/112 ≈ 90%。根据这次抽查做了三处修正：
- `cat_only`：太小的物体不再出这类题；
- `group`：提示词要求句子点到每一个目标；
- `hneg_*`：新增规则，位置词与原句不同的负例直接丢弃。

## 3. 诊断评测（`glance_data.eval.diagnose`）

条件：300 张 refcoco_val 图片，训练时没有用过；checkpoint 是只用现有数据训练的 vlm-jev v2（Qwen3.5-4B 基座）；共 23,586 题。同一批图片用原始人工描述提问时，Acc@0.5 为 **93.4%**。

| 题型 | 结果 |
|---|---|
| long / medium / casual / short | Acc@0.5 84.6 / 82.4 / 80.1 / 76.6%，中英文相差约 1 个点 |
| cat_only（只说类别名，图中唯一物体） | **Acc@0.5 40.3%**，判为存在的只有 74.5% |
| hneg_attribute（同类，颜色等细节不对） | **判为“没有” 16.4%** |
| hneg_relation（同类，动作或关系不对） | **判为“没有” 8.1%** |
| neg_count（数量不对） | 判为“没有” 56.8% |
| neg_position / neg_near | 判为“没有” 87.5 / 91.2% |
| group / gref_multi（多目标） | 判为存在 99.5 / 98.8%，但单框只能命中其中一个目标 |
| cat_all（全部实例） | 判为存在 85.6%，命中任一目标 36.5% |
| function（按用途描述） | 判为存在只有 54.9% |

结论：模型在现有数据覆盖到的分布上表现很强，包括类别不在图中的容易负例和 RefCOCO 式的描述。在新数据针对的维度上明显薄弱：只说类别名、同类难负例、数量、多目标和按用途描述。抽查中难负例的标签 16/16 全部正确，所以这些低分反映的是模型能力，不是标签噪声。
