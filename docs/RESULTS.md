# 结果

原始结果在 `docs/results/` 下：`analysis.json` 是现有数据的诊断，`audit_2026-11-18.json` 是人工抽查记录。

## 1. 现有数据的问题（`glance_data.analyze`）

统计对象是现有训练集：24,407 张图，355,385 题。

| 问题 | 数字 |
|---|---|
| 具体程度两极分化 | RefCOCO/+ 的描述中位数是 3 个词，22–26% 连名词都没有（如 “green shirt”、“middle left”）；RefCOCOg 的中位数是 8 个词，18% 超过 12 个词 |
| 每个目标都有同类干扰物 | 100% 的训练目标在图中至少有 2 个同类物体，40% 至少有 4 个。所以“只说类别名”和“全部实例”这两种问法从没出现过 |
| 同类物体覆盖不全 | 面积 ≥0.5% 的物体中，只有 42% 有描述；54% 的图里，同一类物体只描述了一部分。小物体覆盖更低，例如背包 11%、瓶子 16%、杯子 20% |
| 负例太容易 | 78% 的负例提到的类别根本不在图里，14% 没有类别词，只有 7.7% 是“同类存在、描述不符” |
| 多目标描述被丢弃 | gRefCOCO 训练集中有 69,580 条多目标描述没被使用 |
| 语言和类别单一 | 全是英文；按用途描述的不到 1%；48% 的描述指向人 |

benchmark 的问题：

| 问题 | 数字 |
|---|---|
| 测不到“没有”和“多个” | RefCOCO / RefCOCO+ / RefCOCOg 的 8 个评测集里，负例和多目标题都是 0% |
| 评测集不独立 | refcoco_val、refcoco+_val、grefcoco_val 用的是同一批 1,500 张图；9 个评测集实际上只有 3 组图片 |
| 偏重位置词 | refcoco_testB 中 64% 的题只靠位置词就能答对 |
| 标注噪声 | 抽查 refcoco_val 中的题目时，看到了垃圾句（“click anywhere”）、真值框框成整张桌子的“soup”，以及句子说“两块西兰花”却只标了一个框 |

## 2. 标签正确率（分层人工抽查，每类 8 条）

| 题型 | 正确 | 题型 | 正确 |
|---|---:|---|---:|
| long | 8/8 | hneg_attribute | 8/8 |
| casual | 8/8 | hneg_relation | 8/8 |
| medium | 7/8 | neg_count | 8/8 |
| short | 6/8 | neg_position | 8/8 |
| group | 6/8 | neg_near | 7/8 |
| function | 6/8 | cat_all | 8/8 |
| cat_only | 5/8 | gref_multi | 8/8 |

总计 101/112 ≈ 90%。根据这次抽查做了三处修正：
- `cat_only`：太小的物体不再出这类题；
- `group`：提示词要求句子点到每一个目标；
- `hneg_*`：新增规则，位置词与原句不同的负例直接丢弃。

## 3. 诊断集

`make diag-set` 会在 300 张 refcoco_val 图片上运行同一套 pipeline。这些图片从未用于训练。输出是 `out/aug_refcoco_val.jsonl`，按 `kind` 和 `lang` 分组，每组都可以单独统计。拿模型去评测这份诊断集，在模型仓库里做。
